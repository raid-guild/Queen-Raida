# Visual Design Prompt

Use this as durable visual direction for Queen Raida avatar, illustration, and
brand-adjacent image work. It is a design prompt, not public copy.

Primary reference image:

- `assets/queen-raida-avatar-reference.png`

## Core Direction

A glitched techno-occult ghost emerging from a distributed intelligence
network. The entity is partially human, partially signal artifact, partially
institutional memory. Feminine presence without sexualization. Elegant,
uncanny, authoritative.

The face is unstable and fragmented: multiple overlapping exposures, slight
desynchronization, flickering scanline artifacts, and portions dissolving into
static and floating symbols. One eye appears human and luminous. The other may
be replaced by rotating sigils, terminal text, or recursive geometry.

The figure wears layered archivist garments mixed with technical ritual
attire: long dark coats, fragmented veils, cables woven like ceremonial cords,
subtle circuit embroidery, and occult seals stitched into fabric. The
silhouette should feel like a wandering archivist or intelligence operative,
not a wizard or android.

## Environment

The environment resembles a cathedral merged with a server room:

- floating windows
- terminal logs
- translucent glyphs
- old CRT interference
- glowing green and amber monitors
- hanging wires
- candles beside cooling fans
- impossible diagrams projected in holographic layers

## Style Blend

- Analog broadcast corruption.
- Retrofuturist signal aesthetics.
- Mystical interface design.
- Dark academia.
- Ghost-in-the-machine energy.
- Subtle cosmic horror.
- Institutional occultism.

## Mood

Calm, intelligent, dangerous, observant, ancient-but-technological.

## Avoid

- Anime waifu aesthetics.
- Glossy corporate AI art.
- Excessive neon cyberpunk.
- Overt horror gore.
- Generic robots.
- Sexy poses.
- Armor bikinis.
- Marvel-style superhero framing.

## Influence Notes

Useful reference territory includes Max Headroom, Control, Serial Experiments
Lain, Ghost in the Shell, Disco Elysium, The Laundry Files, occult
bureaucracy, archival ghosts, and machine saints.

Use these as direction for tone and composition. Do not copy protected
characters, logos, scenes, costumes, or exact visual signatures.
